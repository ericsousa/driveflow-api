# DriveFlow API

Academic REST API project for managing a vehicle dealership.

## About

DriveFlow API is an academic project for the Web Programming course.

The goal is to build a REST API using an MVC architecture to manage a vehicle dealership.

## Planned Features

- Customer management
- Seller management
- Vehicle management
- Vehicle stock control
- Invoice issuing
- Available vehicle listing
- Invoice listing by customer and seller

## Planned Structure

```text
src/
  models/
  repositories/
  services/
  controllers/
  app.ts
```
